NS Logger｜碳水與胰島素紀錄

固定使用 Access Token；胰島素為選填，留空時不會上傳胰島素紀錄。網址可記住，Token 可選擇是否儲存在本機。

Access Token 會透過 Nightscout 支援的 token 查詢參數傳送。請勿分享含 Token 的完整請求網址。

Google Sheets 食物換算

兩人於 Google Sheets 共同編輯，NS Logger 僅讀取。係數＝每 1g 食物所含的碳水 g 數。

尚未同步。可使用上次成功同步的資料。

任一欄輸入，另一欄自動換算，並將碳水帶入下方 NS 上傳欄位。

Google Sheets 請使用「檔案 → 共用 → 發布到網路」，選擇 Foods 工作表及 CSV。資料須僅含可公開的食物資訊。

只有確實已施打且知道劑量時才填寫；留空不會送出 insulin 欄位。

預設為目前時間；可調整為過去時間補登。上傳後自動重設為目前時間。
